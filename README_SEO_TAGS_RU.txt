ТЁМНЫЙ АРХИВ — SEO-теги в админке

Изменение:
- В админке stories.html уже есть поля для SEO-тегов и описания историй и статей.
- netlify/functions/content-page.js добавляет значения поля tags в <meta name="keywords"> на индивидуальной странице.
- SEO-теги не выводятся в видимом тексте истории или статьи.
- Публичная функция отдаёт только истории со статусом approved.
- netlify/functions/sitemap.js поддерживает URL индивидуальных материалов.

ВАЖНО:
1. Если поля slug, tags, meta_description и image_url уже добавлялись в Supabase, SQL повторно запускать не нужно. Иначе выполните sql/06_setup_individual_pages_seo.sql один раз в Supabase SQL Editor.
2. Meta keywords не отображаются на странице для обычного посетителя, но Google не использует этот метатег для ранжирования. Уникальные заголовок, описание и текст страницы важнее.
3. Перед публикацией проверьте страницу одной одобренной истории и одной статьи, затем /sitemap.xml.
4. В архив включены файлы, загруженные в этой переписке, и функции Netlify, необходимые для SEO-страниц и карты сайта. Другие SQL-файлы проекта, если они используются в вашем Supabase, не заменяются этим архивом.
